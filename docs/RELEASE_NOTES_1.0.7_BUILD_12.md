# Vistora Mobile 1.0.7 (Build 12)

Release date: 5 October 2026

## Google Play Console - What's new

- Improved recruitment interviews, panel feedback, candidate selection, and offer-letter workflows.
- Added clearer project assignment, supervisor/team visibility, project updates, completion, and rollback flows.
- Improved performance reviews, KPI scoring, search, filters, pagination, and mobile scrolling.
- Fixed mobile refresh, permission, navigation, and stability issues across Recruitment, Projects, and Performance.
- General reliability, security, and usability improvements.

## App Store - What's New

This release makes Vistora more reliable across HR, recruitment, projects, and performance workflows. Interview feedback and candidate status now refresh correctly, while project teams, supervisors, updates, deadlines, completion, and rollback actions are clearer and better aligned with permissions. Performance screens now support improved mobile scrolling, search, filters, pagination, monthly reviews, KPI scoring, and reports. We also resolved mobile action, refresh, navigation, and stability issues and improved the overall HR workspace experience.
