# Vistora Mobile 1.0.7 (Build 15)

Release date: 14 October 2026

## Google Play Console — What's new

- Added Vistora News updates for employees, supervisors, and tenant HR/admin users, with targeted announcements, links, filters, pagination, and dismissible latest-news alerts.
- Added employee directory exports, including full employee details with salary structure in Excel, individual PDF, and ZIP formats.
- Improved supervisor visibility so employees assigned to multiple supervisors appear correctly for every assigned supervisor.
- Improved live API compatibility, reliability, and mobile usability across HR, employee, and supervisor workflows.

## App Store — What's New

Build 15 adds Vistora News updates with targeted announcements and convenient filtering, full employee directory exports in Excel/PDF/ZIP formats, and more reliable supervisor access for employees assigned to multiple supervisors. This release also includes live API compatibility, reliability, and mobile usability improvements.
