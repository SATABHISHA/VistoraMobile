# Vistora Mobile 1.0.7 (Build 13)

Release date: 6 October 2026

## Google Play Console — What's new

- Added Support Tickets to the superadmin mobile workspace.
- Superadmins can search and filter tenant support tickets by tenant, status, and priority.
- Added mobile pagination and selectable rows per page for support ticket history.
- Added ticket conversation replies, tenant and requester context, issue resolution, and ticket closing.
- Improved support ticket navigation and mobile usability.
- General reliability, performance, and security improvements.

## App Store — What's New

Superadmins can now manage Vistora Support Tickets directly from the mobile app. Search and filter tenant conversations, choose how many tickets to view per page, move through paginated results, reply to users, and resolve or close issues from a mobile-friendly support workspace. Navigation, ticket context, reliability, and overall performance have also been improved.
